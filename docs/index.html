POCKETLEDGER・產品規劃

多幣記帳 iPhone App

個人用多幣別記帳：記錄新台幣與外幣收支，依交易日自動換算匯率，計入刷卡手續費，並在預算接近或超出時用本機通知提醒。資料只存在 iPhone，不使用雲端。

僅 iPhone・iOS 17+SwiftUI + SwiftData無雲端、無帳號繁體中文

功能MVP 內容
新增交易支出／收入／退款／繳卡費；金額與幣別、日期、分類、國家／地區、付款方式、卡片、商家、備註、收據照片

統計報表月／年／自訂期間；收入、支出（含費）、手續費、結餘；各幣別原始金額分開列；多維篩選與圖表
信用卡帳單刷卡記支出；繳卡費為轉帳不計支出；卡片頁顯示累計刷卡、已繳、估計未繳

02主要操作流程

記一筆外幣刷卡消費

  1. 總覽或紀錄頁點 ＋，類型預設為「支出」。
  2. 幣別選 JPY，國家自動帶入日本。
  3. 輸入金額 8000，App 自動查詢交易日臺銀 JPY 即期賣出匯率，即時顯示「≈ NT$1,708」。
  4. 選分類「餐飲」、付款方式「信用卡」、卡片「國泰 CUBE」。
  5. 手續費區自動開啟：NT$1,708 × 3% = NT$51，合計 NT$1,759；可切換「手動調整手續費」。
  6. 選填商家、備註，拍攝收據。
  7. 儲存：寫入匯率快照，檢查預算，達門檻即發通知。

無網路／查無匯率

匯率區顯示橘色提示並自動切換為手動輸入，存檔後標示「手動匯率」。之後可按「改回自動查詢」。

繳信用卡帳單

設定 → 卡片管理 → 選卡片 → 記錄繳卡費。此筆不計入支出，只沖減該卡的估計未繳金額。

退款

選「退款」與原分類、卡片，會沖減該分類支出與預算使用量；銀行退回手續費時開啟「退回手續費」。

換手機

設定 → 備份與還原 → 匯出備份檔；新手機安裝後選「從備份檔還原」。

03頁面與介面設計

金額與幣別永遠在第一屏、字級最大；不常用欄位往下放；外幣與刷卡相關區塊只在需要時出現；說明文字直接寫在各區塊底部。

原生 iOS：Swift 5 + SwiftUI + SwiftData，最低 iOS 17

考量原生 SwiftUIReact Native／Flutter
Face ID、相機、通知、檔案匯出系統框架直接使用需第三方套件橋接
本機資料庫SwiftData 內建需 SQLite／Realm 套件
圖表Swift Charts 內建需第三方套件
只做 iPhone沒有跨平台需求跨平台優勢用不到
依賴與維護零第三方依賴套件升級負擔

本機資料儲存

  • SwiftData（底層 SQLite）存於 App 沙盒，明確關閉 CloudKit；關閉 App 或重新開機資料都會保留。
  • 金額一律用 Decimal，避免浮點誤差。
  • 收據照片存於 Application Support/Receipts/，長邊壓縮至 2000px、JPEG 品質 0.75，並啟用 iOS 資料保護。

歷史匯率保存：不另建匯率表，而是每筆交易存檔時寫入匯率快照（匯率、匯率日期、來源、說明、換算金額）。統計一律使用快照，日後匯率更新不會改變舊紀錄；只有編輯時改了幣別、日期或類型才重新查詢。

備份與還原

格式單一 JSON 檔（記帳備份_YYYY-MM-DD.json），含設定、分類、卡片、預算、提醒狀態、交易，以及 Base64 內嵌的收據照片；金額存成字串確保精確
匯出系統「儲存檔案」面板，可存到「我的 iPhone」、iCloud 雲碟、Google Drive 或 AirDrop；App 自己不上傳
匯入選檔後顯示備份時間與筆數，確認後完整取代目前資料
加密不加密（依需求），介面提示備份檔可被讀取
更換手機iCloud／Finder 整機備份通常會帶走 App 資料；保險做法是先匯出備份檔再還原
刪除 App本機資料與收據照片一併刪除且無法復原
App 鎖定密碼不在備份中，新手機需重新設定

06核心計算邏輯

匯率換算與刷卡手續費

amountTWD    = round(原幣金額 × 匯率, 小數 2 位)
適用手續費   = 支出或退款，且（信用卡，或金融卡且已開啟）
               且（未開啟「僅外幣」或幣別 ≠ TWD）
費率         = 卡片個別費率 ?? 預設費率 3%
手續費       = round(amountTWD × 費率, 整數元)   ← 可改為手動金額
含手續費總額 = amountTWD + 手續費
USD 100 × 31.5NT$3,150 手續費 3%（94.5 → 95）NT$95 含手續費總額NT$3,245 新增交易與明細畫面都會顯示這兩行公式

支出預設計入手續費；退款預設不退回手續費，可手動開啟。修改費率設定不會回溯已存交易。

收支統計

淨支出   = Σ 支出(amountTWD + 手續費) − Σ 退款(amountTWD + 退回手續費)
手續費   = Σ 支出手續費 − Σ 退回手續費
消費金額 = 淨支出 − 手續費
結餘     = 收入 − 淨支出
繳卡費   不計入以上任何一項，另列「信用卡繳款」
各幣別   依幣別分組各自加總，不跨幣別相加

信用卡帳單：消費當下認列

  • 刷卡當下記「支出」，支出、分類與預算即時反映。
  • 繳卡費記「繳卡費」（新台幣），屬轉帳，不計入收入或支出，所以不會重複計算。
  • 卡片頁：累計刷卡（含手續費）− 退款 − 已繳款 = 估計未繳金額。
  • 帳單手續費與自動計算不同時，到該筆交易「手動調整手續費」。

預算與提醒

  • 週期：每月 N 日（1–28，預設 1）至次月 N−1 日。
  • 使用量（新台幣）＝週期內淨支出，含手續費並扣除退款；外幣用各筆保存的匯率換算結果。
  • 門檻：接近門檻預設 80%（可調 50–95%）與固定的 100%。
  • 評估時機：新增、編輯、刪除交易，修改預算，App 啟動或回到前景。
  • 同一週期、同一預算、同一門檻只提醒一次；一次跨過多個門檻時只通知最高者。新週期自動重設。
  • 修改預算後，若使用率降到某門檻以下，清除該門檻紀錄，之後再次達到時會重新提醒。
通知範例：預算提醒：餐飲 已達 80%｜本期已支出 NT$8,200／預算 NT$10,000（使用 82%）

App 鎖定

  • 模式：不鎖定、6 位數 App 密碼、Face ID（同時設定 App 密碼作為備援）。裝置無法使用 Face ID 時停用該選項。
  • 密碼以隨機鹽加 SHA-256 雜湊存於 Keychain（僅限本機）。
  • App 進入背景即上鎖；多工切換畫面以模糊遮罩隱藏帳目。關閉或切換鎖定需先驗證。

08MVP 與後續擴充

MVP（已交付）：上述 10 項功能全部可操作，並附核心計算的單元測試。目前以網頁版（PWA）為主要版本，iOS 原生版暫停維護。

網頁版 1.1 已加入：首頁備份提醒、返回手勢、再記一筆、旅程標籤、商家名稱建議。1.2：信用卡結帳日／繳款日與繳款提醒、月趨勢圖、CSV 匯出。

匯率與信用卡

  • 批次重新查詢匯率、選擇匯率類型
  • 離線時稍後自動補查
  • 結帳日、繳款日與繳款提醒
  • 依帳單週期對帳、分期付款

記帳效率

  • 常用範本、重複交易
  • Widget、Siri 捷徑
  • 收據 OCR 自動帶入金額與商家
  • 旅行模式（以旅程統計）

報表與資料

  • 趨勢圖、與上期比較
  • Excel／CSV／PDF 匯出
  • 備份加密、定期備份提醒、合併匯入
  • 銀行帳戶與外幣帳戶餘額

平台

  • iCloud 同步
