# 多幣記帳（PocketLedger）產品規劃與設計

> 個人用、僅限 iPhone、資料只存在本機的多幣別記帳 App。
> 本文件依序說明：需求整理 → 操作流程 → 頁面與介面設計 → 資料欄位 → 技術方案 → 核心計算邏輯 → 預設值清單 → MVP 範圍與後續擴充。

> **版本狀態（2026-11）**：以網頁版（PWA，`docs/app/`）為主要版本並持續維護；iOS 原生版（`App/`）暫停維護。網頁版 1.1 已加入首頁備份提醒、返回手勢、再記一筆、旅程標籤與商家名稱建議；1.2 加入信用卡結帳日／繳款日與繳款提醒、月趨勢圖、CSV 匯出；1.3 加入外幣現金錢包（換匯與平均成本）、依信用卡帳單對帳、代墊／分帳、旅程預算，以及自動化測試；1.4 交易紀錄改為月曆檢視（可切換清單）；1.5 介面美化：線條圖示、設定頁彩色圖示、新 App 圖示、頁面滑入動畫、金額千分位、表單「更多選項」與下方儲存鈕、左滑刪除、首頁近 7 天支出圖；1.6 刪除交易後 6 秒內可復原（含收據照片）；1.7 離線時使用最近一次查到的匯率並可補查、固定收支自動記帳，並提供實機測試清單；1.8 設定中可選擇跟隨系統、淺色或深色外觀。

## 2. 主要操作流程

### 2.1 記一筆外幣刷卡消費（最常見）
1. 總覽或紀錄頁點 **＋**。
2. 類型預設「支出」；點幣別選單選 **JPY**（國家自動帶入 🇯🇵 日本）。
3. 輸入金額 `8000` → App 自動查詢交易日臺銀 JPY 即期賣出匯率，即時顯示「≈ NT$1,708」。
4. 選分類「餐飲」、付款方式「信用卡」、卡片「國泰 CUBE」。
5. 手續費區自動開啟：`NT$1,708 × 3% = NT$51`，合計 NT$1,759（可切換「手動調整手續費」）。
6. （選填）商家、備註、拍收據。
7. 儲存 → 匯率快照寫入 → 檢查預算 → 達門檻即發通知。

### 2.2 無網路／查無匯率
查詢失敗 → 匯率區顯示橘色提示「目前無法連線，請手動輸入匯率」→ 自動切換為手動輸入欄位 → 存檔後標示「手動匯率」。之後可在編輯畫面按「改回自動查詢」。

### 2.3 繳信用卡帳單
設定 → 卡片管理 → 選卡片 → **記錄繳卡費**（或新增交易選「繳卡費」）→ 輸入新台幣金額 → 儲存。此筆不計入支出，只沖減該卡「估計未繳」。

### 2.4 退款
新增交易選「退款」、選原分類與卡片 → 沖減該分類支出與預算使用量；若銀行同時退回國外交易手續費，開啟「退回手續費」。

### 2.5 設定預算
預算分頁 → 編輯預算 → 輸入總預算及各分類預算 → 儲存。週期起始日、提醒門檻在 設定 → 預算週期與提醒。

### 2.6 備份與換機
設定 → 備份與還原 → 匯出備份檔 → 選擇存到「檔案」或 iCloud 雲碟／AirDrop。新手機安裝後 → 從備份檔還原。

```

├─ 總覽 HomeView
│   ├─ 本期卡片：支出（含手續費）大字、收入／手續費／結餘
```

### 新增交易畫面（由上而下）
1. **類型分段控制**：支出｜收入｜退款｜繳卡費
2. **金額列**：左側粗體幣別按鈕（點開常用幣別選單）、右側 36pt 大字金額、數字鍵盤；下方「其他幣別…」與「換算新台幣」
3. **交易日匯率**（外幣才顯示）：`1 JPY = 0.2135 TWD`、匯率日期、資料來源、重新查詢／改用手動
4. **日期、分類、國家／地區、付款方式、卡片**
5. **刷卡手續費**（刷卡才顯示）：開關、費率來源、手動調整、消費／手續費／合計拆解與換算公式
6. **商家與備註**
7. **收據照片**：拍攝、相簿、預覽、移除
8. 右上「儲存」（金額與匯率有效才可按）

設計原則：金額與幣別永遠在第一屏、字級最大；不常用欄位往下放；外幣與刷卡相關區塊只在需要時出現；所有說明文字都直接寫在區塊底部。

id、name、icon（SF Symbol）、kindRaw（expense/income）、sortOrder。

### PaymentCard（卡片）
id、name（別名）、lastFour、kindRaw（credit/debit）、customFeeRate（nil = 用預設）、sortOrder、createdAt。

id、isTotal、category（分類預算）、amount（新台幣／月）。

## 5. 技術方案

### 5.1 選擇：原生 iOS（Swift 5 + SwiftUI + SwiftData），最低 iOS 17
| 考量 | 原生 SwiftUI | React Native / Flutter |
|------|--------------|------------------------|
| Face ID、相機、本機通知、檔案匯出 | 系統框架直接使用 | 需第三方套件橋接 |
| 本機資料庫 | SwiftData 內建，免套件 | 需 SQLite／Realm 套件 |
| 圖表 | Swift Charts 內建 | 需第三方套件 |
| 只做 iPhone | 無跨平台需求 | 跨平台優勢用不到 |
| 依賴與維護 | **零第三方依賴** | 套件升級負擔 |

結論：只做 iPhone、重度使用系統功能、個人長期使用 → 原生最簡單、最穩定。iOS 17 起才有 SwiftData、`ContentUnavailableView`、`SectorMark`，近年 iPhone 皆可升級。

### 5.2 本機資料儲存
- **SwiftData**（底層為 SQLite），存於 App 沙盒的 Application Support，明確設定 `cloudKitDatabase: .none`，不做雲端同步。
- 金額一律用 `Decimal`，避免浮點誤差。
- 收據照片存於 `Application Support/Receipts/<UUID>.jpg`，長邊壓縮至 2000px、JPEG 0.75（約 200–500KB），檔案啟用 iOS 資料保護。
- 關閉 App 或重新開機資料都會保留。

### 5.3 匯率查詢（已確認支援歷史匯率）
| 順序 | 來源 | 串接方式 | 歷史資料 | 更新 | 限制 |
|------|------|----------|----------|------|------|
| 1 | **臺灣銀行牌告匯率** | `GET https://rate.bot.com.tw/xrt/flcsv/0/{yyyy-MM-dd}`，回傳 CSV，免金鑰 | 有，可依日期查詢 | 營業日 09:00 起盤中多次 | 僅 19 種外幣；週末假日無牌告；非正式 API，格式可能變動 |
| 2 | **fawazahmed0 Currency API** | `GET https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@{yyyy-MM-dd}/v1/currencies/{code}.json`，備援網址 `https://{date}.currency-api.pages.dev/...`，免金鑰 | 2024-03 起 | 每日一次 | 市場中間價（非銀行賣價）；社群維護 |
| 3 | 手動輸入 | — | — | — | 標示「手動匯率」 |

細節：
- 支出／退款取臺銀「即期賣出」（你買外幣的價格，最接近刷卡換算），收入取「即期買入」；KRW、VND、PHP、IDR、MYR 等無即期報價者改用現金匯率。
- 交易日無牌告（週末／假日）時，往前最多找 7 天，採最近營業日並顯示實際匯率日期。
- 未來日期以今天查詢。
- 同一日的臺銀牌告在記憶體快取，同一 App 開啟期間不重複下載。

### 5.4 歷史匯率保存
匯率不另建匯率表，而是**每筆交易存檔時寫入匯率快照**：`exchangeRate`、`rateDate`、`rateSource`、`rateDetail`、`amountTWD`。之後任何統計都直接用快照，不會因日後匯率更新改變；只有使用者編輯該筆並改了幣別／日期／類型時才重新查詢。

### 5.5 備份與還原
- **格式**：單一 JSON 檔（`記帳備份_YYYY-MM-DD.json`），含 formatVersion、設定、分類、卡片、預算、提醒狀態、交易，以及 Base64 內嵌的收據照片。金額存成字串確保精確。選 JSON 是因為不需第三方壓縮套件、人可讀、未來可轉成其他格式。
- **匯出**：系統「儲存檔案」面板，由使用者選擇「我的 iPhone」、iCloud 雲碟、Google Drive 等；App 自己不上傳。
- **匯入**：選檔 → 顯示備份時間與筆數 → 確認後**完整取代**目前資料（第一版不做合併，避免重複）。
- **不加密**（依需求）；介面明確提示備份檔可被讀取，請妥善保存。
- **換手機**：iCloud／Finder 整機備份通常會帶走 App 資料；保險做法是先匯出備份檔再還原。
- **刪除 App**：本機資料與收據照片會一併刪除且無法復原。
- App 鎖定密碼不在備份中，新手機需重新設定。

## 6. 核心計算邏輯

### 6.1 匯率換算
```
amountTWD = round(amount × exchangeRate, 2 位小數)
```

### 6.2 刷卡手續費
```
適用條件：類型為支出或退款，且
  付款方式 = 信用卡，或（金融卡 且 設定「金融卡也計算」）
  且（未開啟「僅外幣」或 幣別 ≠ TWD）
費率 = 卡片個別費率 ?? 全域預設費率（3%）
手續費 = round(amountTWD × 費率, 整數元)   ← 可改為手動金額
含手續費總額 = amountTWD + 手續費
```
- 支出預設「計入手續費」；退款預設「不退回手續費」，可手動開啟。
- 外幣刷卡範例：USD 100 × 31.5 = NT$3,150；NT$3,150 × 3% = NT$94.5 → NT$95；合計 NT$3,245。畫面同時顯示這兩行公式。
- 修改費率設定不回溯已存交易（每筆保存 feeRate、feeTWD）。

### 6.3 收支統計
```
淨支出 = Σ 支出(amountTWD + 手續費) − Σ 退款(amountTWD + 退回手續費)
手續費 = Σ 支出手續費 − Σ 退回手續費
消費金額（不含費）= 淨支出 − 手續費
收入 = Σ 收入 amountTWD
結餘 = 收入 − 淨支出
繳卡費：不計入以上任何一項，另列「信用卡繳款」
各幣別：依 currency 分組，各自加總原幣支出、退款、收入；不跨幣別相加
```

### 6.4 信用卡帳單處理（建議做法：消費當下認列）
- 刷卡當下就記一筆「支出」→ 支出、分類、預算即時反映。
- 繳卡費時記一筆「繳卡費」（類型 cardPayment，新台幣）→ 屬轉帳，**不計入收入或支出**，因此不會重複計算。
- 卡片頁提供：累計刷卡（含手續費）− 退款 − 已繳款 = **估計未繳金額**，方便對帳。
- 若帳單上的國外交易手續費與自動計算不同，到該筆交易「手動調整手續費」即可。

### 6.5 預算與提醒
- 週期：每月 N 日（1–28，預設 1）至次月 N−1 日。
- 使用量（新台幣）= 週期內淨支出（含手續費、扣退款）；分類預算只算該分類。外幣用各筆保存的匯率換算結果。
- 門檻：接近門檻（預設 80%，可調 50–95%）與 100%（固定）。
- 觸發時機：新增／編輯／刪除交易、修改預算、App 回到前景、App 啟動。
- 每次評估：對每個預算檢查已達且未記錄的門檻 → 全部寫入 `BudgetAlertRecord` → 只通知最高門檻（例如一次從 50% 跳到 120%，只發「已超出預算」）。
- **同一週期、同一預算、同一門檻只提醒一次**；新週期（periodKey 不同）自動重設並清除舊紀錄。
- **修改預算時**：若新金額下使用率已低於某門檻，移除該門檻的紀錄，之後再次達到時會重新提醒；仍達到者保留紀錄，不重複通知。刪除的預算一併清除紀錄。
- 通知內容：標題含預算名稱與門檻，內文「本期已支出 NT$8,200／預算 NT$10,000（使用 82%）」。

### 6.6 App 鎖定
- 模式：不鎖定、App 密碼（6 位數）、Face ID（同時設定 App 密碼作為備援）。
- 裝置無 Face ID 或未設定時，Face ID 選項停用並提示改用密碼。
- 密碼以 16 bytes 隨機鹽 + SHA-256 雜湊存於 Keychain（`WhenUnlockedThisDeviceOnly`）。
- App 進入背景即上鎖；多工切換畫面以模糊遮罩隱藏帳目。
- 關閉鎖定或切換模式需先驗證（密碼或 Face ID）。
